Getting Started

An introduction to the DarkvoyagerLabs wiki — what it is, how to navigate it, and where to start.

A

Author: Admin

17 September 20262 min read

On this page

    Welcome to the DarkvoyagerLabs wiki. This is where guides, docs and lore live for every project in the catalogue.

    How to read a post

    Every post has a header with a title, an author line, and a date. Below that, the body can contain any HTML you want — headings, lists, images, code blocks, links, whatever the post needs.

    Browsing the wiki

    • Go to the wiki index to see all posts.
    • Click any post card to open it.
    • Scroll to the bottom of any post to leave a comment.

    Attachments

    Some posts include downloadable files. They appear in the Attachments section below the post body. For example:

    • Download image1.jpg

    Comments

    Every post has a comment section at the bottom powered by GitHub Discussions.

    How to upload your own post

    For now, there is no dedicated backend for log in and one-tap uploads, but if you want your post to be uploaded in the wiki, you can do the following.

    1. Create a .docx / .odt / .md / .txt file and write the contents with specified Headings and body.
    2. You can add image files and text formatting too.
    3. Save the file with name same as the main heading. E.g: This post have main heading "Getting Started".
    4. Mail at connect@darkvoyagerlabs.com with this exact Email subject: "DVL WIKI CONTENT". Our AI automatically sorts out emails with exact same subject and submit them for review and further deploys in the wiki.
    5. If any other attachments are to be added, attach them in the same email.
    6. In the body of the email, kindly write your username, which will reflect in the post.
